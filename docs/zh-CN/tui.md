# 交互式界面（TUI）

Pi 的交互模式提供全屏终端 UI，用于对话、流式响应和会话管理。

## 布局

### 顶部栏

显示高层会话上下文（当前模型、状态、提示）。具体内容可能随 UI 演进而变化。

### 对话视图

主区域展示对话历史。
- **用户消息**：以强调色高亮。
- **智能体消息**：渲染为 Markdown。
- **思考块**：以弱化色斜体显示。
- **工具调用/结果**：展示工具执行与输出的结构化块。

### 编辑器

底部的输入区域。
- **单行 + 多行编辑**（见下方快捷键）。
- **自动补全**支持 `@file` 引用、`/commands` 和资源名称。
- 粘贴与编辑行为遵循已配置的按键绑定。

### 底部栏

显示会话统计与状态。
- Token 使用量（输入/输出）与预估费用。
- 编辑器模式提示（单行 vs 多行）。
- 当前状态消息。

## 显示控制

| 操作 | 快捷键 | 描述 |
|--------|----------|-------------|
| **切换思考过程** | `Ctrl+T` | 隐藏/显示思考块以减少干扰。 |
| **滚动历史** | `PageUp` / `PageDown` | 滚动对话视图。 |

## 操作员遥测

设置 `PI_PERF_TELEMETRY=1` 可启用有界的进程内计时采样，用于长集群运行期间的操作员诊断。采样仅包含计时信息：不包含提示、工具参数、提供方负载、转录文本或凭据。运行时摘要使用 `pi.operator_tail_latency.v1` schema，包含提供方流式传输、本地工具、扩展宿主调用、会话追加/索引工作以及 TUI 渲染阶段的 p95、p99 和 p999 窗口。帧预算快照使用 `pi.tui.frame_budget.v1` schema，覆盖大会话、工具预览、模型选择器、分支选择器和树选择器界面，这些快照的确定性回归证据记录在 `docs/evidence/large-session-tui-frame-budget.json` 中。

该遥测是操作员交接辅助手段，而非发布级性能证据。面向发布的速度声明仍需 `tests/perf/reports/`、`docs/evidence/` 以及性能 SLI 契约下的实测产物与新鲜度门禁。

## 导航与浮层

### 键盘快捷键（`/hotkeys`）
使用 `/hotkeys` 查看当前快捷键列表（包括来自 `~/.pi/agent/keybindings.json` 的用户覆盖）。

## 斜杠命令

在编辑器中输入斜杠命令（以 `/` 为前缀）并按 Enter。

`/help` 是权威的应用内列表。本节记录 `src/interactive.rs` 中当前已实现的命令面。

| 命令 | 描述 |
|---------|-------------|
| `/help` (`/h`, `/?`) | 显示帮助文本与快捷键提示。 |
| `/login [provider]` | 登录/设置凭据（内置项为 OAuth；支持的提供方会提示输入 API 密钥）。不带参数运行可查看状态表。 |
| `/logout [provider]` | 移除已存储的 OAuth 凭据。 |
| `/clear` (`/cls`) | 清空对话视图/历史。 |
| `/model [id|provider/id]` (`/m`) | 显示或切换当前模型。 |
| `/thinking [level]` (`/think`, `/t`) | 设置思考级别（`off|minimal|low|medium|high|xhigh|max`）。 |
| `/scoped-models [patterns\|clear]` (`/scoped`) | 显示或设置用于 Ctrl+P 循环的模型模式。 |
| `/history` (`/hist`) | 显示输入历史。 |
| `/export [path]` | 导出对话为 HTML。 |
| `/session` (`/info`) | 显示会话信息（路径、Token、费用）。 |
| `/settings` | 打开设置选择器 UI。 |
| `/theme [name]` | 列出或切换主题（见 `docs/themes.md`）。 |
| `/resume` (`/r`) | 选择并恢复之前的会话。 |
| `/new` | 开始新会话。 |
| `/copy` (`/cp`) | 将最后一条智能体消息复制到剪贴板。 |
| `/name <name>` | 设置会话显示名称。 |
| `/hotkeys` (`/keys`, `/keybindings`) | 显示键盘快捷键。 |
| `/changelog` | 显示变更日志条目。 |
| `/tree` | 显示会话分支树摘要。 |
| `/fork [id\|index]` | 从用户消息分叉（默认：当前路径上的最后一条）。 |
| `/compact [notes]` | 使用可选指令压缩较早的上下文。 |
| `/reload` | 从磁盘重新加载技能/提示。 |
| `/template <name> [args]` | 按名称展开提示模板。 |
| `/share` | 将会话 HTML 上传为私密 GitHub gist 并显示 URL。 |
| `/exit` (`/quit`, `/q`) | 退出 Pi。 |

### 模型选择
- 使用 `/model` 切换模型（按 `provider/id` 或模糊匹配）。
- 某些构建还定义了 `Ctrl+L`（模型选择器）和 `Ctrl+P`（循环模型）等快捷键。如果某个快捷键出现在 `/hotkeys` 中却无响应，说明该构建尚未接入。

### 会话选择器（`/resume`）
无需重启 Pi 即可浏览并恢复之前的会话。
- `Enter`：选择会话
- `Ctrl+D`：删除会话（需确认）

### 树导航器（`/tree`）
可视化对话分支结构。
- `Up` / `Down`：导航节点
- `Enter`：切换到所选节点（若非叶子则分叉）
- `Ctrl+U`：切换仅用户视图（隐藏智能体/工具干扰）

### 设置（`/settings`）
即时修改配置（思考级别、主题、消息投递模式）。

## 消息队列

当 Pi 正在生成响应或运行工具时，你仍可输入。

- **队列转向（`Enter`）**：在当前步骤完成后将你的消息作为转向中断发送。
- **队列后续（`Alt+Enter`）**：将消息加入后续队列，在智能体空闲时处理。
- **恢复已排队消息（`Alt+Up`）**：将已排队的消息拉回编辑器（适用于误排队的情况）。

队列非空时会在编辑器上方可见。
