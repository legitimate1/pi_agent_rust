# 会话树导航

Pi 的会话是**树**，而非扁平的消息列表。每个条目都有 `id` 和可选的 `parentId`，会话会跟踪当前的 **leaf** 指针（你在树中的当前位置）。

使用 `/tree` 导航会话树并切换 leaf。

## `/tree` 与 `/fork` 的区别

| 功能 | `/tree` | `/fork` |
|---------|---------|---------|
| 变更内容 | 同一会话文件内的 leaf 指针 | 从选定点创建**新的会话文件** |
| 适用场景 | 快速分支切换 / 探索替代方案 | 将分支切入独立会话 |
| 摘要 | 可选的分支摘要提示 | 无分支摘要提示 |

## 树视图 UI

树视图 UI 以深度优先列表加缩进展示，并用 `← active` 标记当前 leaf。

### 快捷键

| 按键 | 操作 |
|-----|--------|
| ↑/↓ | 移动选区 |
| Enter | 选中节点 |
| Escape / Ctrl+C | 取消 |
| Ctrl+U | 切换“仅用户消息”（隐藏智能体/工具条目以获得更简洁视图） |
| Ctrl+O | 切换“显示全部”（包含标签/自定义等隐藏的偏系统条目） |

### 选中行为

Pi 有两种不同的选中模式，取决于你选中的内容：

1) **用户消息（或自定义消息）**
   - leaf 被设置为所选节点的**父节点**（若所选节点为根则为 `null`）。
   - 选中的文本会被放入编辑器，以便你编辑后重新提交、创建新分支。

2) **非用户消息（智能体/工具/压缩等）**
   - leaf 被设置为**所选节点**。
   - 编辑器保持不变/为空；你将从该点继续。

## 分支摘要

切换分支时，Pi 可能会提示对离开的分支进行摘要。提示提供：

1) **不摘要**
2) **摘要**
3) **使用自定义提示进行摘要**（打开小型输入框以输入额外聚焦指令）

### 提示控件

- **摘要选择**：↑/↓ 选择，Enter 确认，Escape/Ctrl+C 取消。
- **自定义提示**：输入指令（Backspace 编辑），Enter 开始摘要，Escape/Ctrl+C 返回选择列表。

### 摘要内容

摘要覆盖从旧 leaf 回溯至与所选目标的公共祖先之间的**已放弃路径**。若遇到**压缩**节点，摘要会提前停止。

### 存储

摘要以 `branch_summary` 会话条目的形式存储，并附加到**新的 leaf**，以便模型在你稍后返回该分支时快速恢复上下文。
