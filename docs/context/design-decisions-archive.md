## D56: subagent 工具注册 — ToolRegistry 显式分支 opt-in

**决策**：选在 ToolRegistry::new 增加 "subagent" 显式分支按名启用，需 --tools subagent 显式开启，不选自动注册或扩展隐式拉起。

**理由**：subagent 底座已合入但工具列表仅暴露扩展 workflow，缺分支被 _=>{} 静默丢弃导致原生 subagent 不可见。

**不选 B 的原因**：自动注册会让未显式启用的上下文意外拉起子进程并触及限深与隔离开销；扩展隐式方式与原生工具可审计性不一致。

**何时重新考虑**：若 subagent 成为默认能力或需按会话策略默认可用，再评估默认启用或按配置分级开放。
